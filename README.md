# Hit-Song-Prediction-Model

# Predicting Hit Songs with Machine Learning
🎵 Can data help predict a hit song? This project explores the intersection of music and machine learning by creating a model that predicts whether a song will become a hit based on its audio features (e.g., danceability, energy, loudness). The goal is to provide actionable insights for the music industry by leveraging data-driven methods.

# Project Overview
This project uses historical data from the Billboard Hot 100 (2000–2023) and the Million Songs Dataset to analyze and predict hit songs. A balanced dataset was created, followed by descriptive analysis and machine learning model development. The best-performing model, Random Forest, achieved a precision of 87.8%, making it suitable for applications where minimizing false positives is critical.

# Features
Scraping Billboard Hot 100: Extracted data on hit songs from 2000 to 2023.
Audio Features Analysis: Merged with the Million Songs Dataset, which includes features like:
danceability
energy
loudness
valence
tempo, and more.

# Descriptive Analysis:
Explored patterns in hit vs. non-hit songs.
Key findings include differences in loudness, energy, and danceability.

# Machine Learning Models:
Tested three algorithms: Logistic Regression, Random Forest, and Adaboost.
Random Forest achieved the best precision at 87.8%.
Insights for the Music Industry:
Patterns and predictions can guide marketing strategies, resource allocation, and content recommendation.

# Key Insights

Hit songs tend to have higher loudness, energy, and danceability.
Shorter durations often correlate with higher replay value.
Genre Trends:

Country, dance, and hip-hop dominate the charts.
Model Applications:

Record labels and marketers can use this model to identify promising tracks, allocate resources effectively, and optimize campaigns.
